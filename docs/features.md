# 喵乐个鱼（miaolegeyu）功能清单

## 模块一：用户系统

### 1.1 用户注册与登录

| 属性 | 说明 |
|------|------|
| **功能名称** | 微信一键登录 |
| **入口路径** | 首次打开小程序自动触发 / pages/profile/profile |
| **操作流程** | 1. 小程序启动 → 2. 调用 wx.login() 获取 code → 3. 调用 userLogin 云函数 → 4. 返回用户信息/自动注册 |
| **涉及云函数** | `userLogin` |
| **前置条件** | 微信账号已授权小程序 |
| **数据库集合** | users |

**详细说明：**
- 支持新用户自动注册，无需填写额外信息
- 自动获取微信头像和昵称作为初始资料
- 登录后生成自定义的 openId 和 unionId 映射
- 支持静默登录（无需用户主动点击授权）

---

### 1.2 用户信息管理

| 属性 | 说明 |
|------|------|
| **功能名称** | 个人资料编辑 |
| **入口路径** | 我的 → 设置 → 编辑资料（package-user/settings） |
| **操作流程** | 1. 进入个人中心 → 2. 点击头像区域 → 3. 修改昵称/头像/个性签名 → 4. 保存 |
| **涉及云函数** | `updateUserInfo`, `getAvatars` |
| **前置条件** | 已登录 |
| **数据库集合** | users |

**子功能：**
- 头像更换（支持从预设头像库选择或上传自定义图片）
- 昵称修改
- 个性签名设置
- 性别设置

---

### 1.3 匿名模式

| 属性 | 说明 |
|------|------|
| **功能名称** | 匿名参与切换 |
| **入口路径** | 我的 → 设置 → 匿名模式开关（package-user/settings） |
| **操作流程** | 1. 进入设置页面 → 2. 开启/关闭匿名模式 → 3. 确认切换 |
| **涉及云函数** | `setAnonymousMode` |
| **前置条件** | 已登录 |
| **效果** | 开启后，在投票、拼单等活动中显示为"匿名用户"而非真实昵称 |

## 模块二：投票聚餐系统

### 2.1 发起活动（创建房间）

#### 2.1.1 Mode A - 我选好了

| 属性 | 说明 |
|------|------|
| **功能名称** | 发起"我选好了"模式投票 |
| **入口路径** | 首页 → 发起聚会 → 选择"我选好了"（package-create/create-mode-a） |
| **操作流程** | 1. 点击发起聚会 → 2. 选择模式A → 3. 填写活动标题/描述 → 4. 上传候选餐厅海报或手动添加选项 → 5. 设置可见性/密码/截止时间 → 6. 创建并分享 |
| **涉及云函数** | `createRoom` (mode: 'a') |
| **前置条件** | 已登录 |
| **数据库集合** | rooms, room_participants |

**特殊能力：**
- 支持上传多张餐厅海报作为投票选项
- 每个选项可附加描述文字（如推荐理由）
- 可设置每人可投票数（单选/多选）

#### 2.1.2 Mode B - 你们来定

| 属性 | 说明 |
|------|------|
| **功能名称** | 发起"你们来定"模式投票 |
| **入口路径** | 首页 → 发起聚会 → 选择"你们来定"（package-create/create-mode-b） |
| **操作流程** | 1. 点击发起聚会 → 2. 选择模式B → 3. 设定筛选条件（菜系/预算/人数/距离）→ 4. 可选择是否允许参与者提议新选项 → 5. 创建并分享 |
| **涉及云函数** | `createRoom` (mode: 'b') |
| **前置条件** | 已登录 |
| **数据库集合** | rooms, room_participants |

**特殊能力：**
- 条件框架式设定，降低发起人决策负担
- 参与者可在框架内提议新的候选选项
- 支持系统根据条件推荐餐厅（调用 searchNearbyRestaurants）

#### 2.1.3 Group Mode - 拼单活动

| 属性 | 说明 |
|------|------|
| **功能名称** | 发起拼单活动 |
| **入口路径** | 首页 → 发起聚会 → 选择拼单（package-create/create-group-order） |
| **操作流程** | 1. 点击发起聚会 → 2. 选择拼单模式 → 3. 选择店铺（从已有店铺列表选或新建）→ 4. 上传/录入商品选项（支持图片+价格）→ 5. 设置截止时间/配送地址 → 6. 创建并分享 |
| **涉及云函数** | `createRoom` (mode: 'group') |
| **前置条件** | 已登录，店铺信息已存在或同步创建 |
| **数据库集合** | rooms, room_participants, group_order_participants |

**特殊能力：**
- 支持外卖拼单和堂食拼单两种场景
- 商品选项支持多选（每人可选择多个商品）
- 自动计算总价和人均费用

---

### 2.2 加入活动

| 属性 | 说明 |
|------|------|
| **功能名称** | 加入房间/活动 |
| **入口路径** | 鱼塘页面点击活动卡片 / 通过分享链接进入（package-vote/vote 或 package-vote/group-detail） |
| **操作流程** | 1. 打开活动详情页 → 2. 点击"加入"按钮 → 3. 如有密码则输入密码 → 4. 确认加入 → 5. 成为参与者 |
| **涉及云函数** | `joinRoom`（普通投票）/ `joinGroupOrder`（拼单） |
| **前置条件** | 房间未锁定、未满员、非重复加入、满足可见性条件 |
| **校验逻辑** | 权限校验 → 密码验证 → 满员检查 → 防重复检查 → 事务写入 |
| **数据库集合** | rooms, room_participants / group_order_participants |

**异常处理：**
- 密码错误提示重试
- 房间已满提示无法加入
- 已加入检测防止重复
- 房间已锁定提示不可再加入

---

### 2.3 提交投票

| 属性 | 说明 |
|------|------|
| **功能名称** | 投票选择 |
| **入口路径** | 活动详情页 → 选择选项 → 确认提交（package-vote/vote） |
| **操作流程** | 1. 浏览候选选项 → 2. 点击选中一个或多个选项 → 3. （可选）填写备注 → 4. 提交投票 → 5. 查看实时票数更新 |
| **涉及云函数** | `submitVote` |
| **前置条件** | 已加入该房间、房间未锁定、未超过投票截止时间 |
| **数据库集合** | votes, rooms |

**特性：**
- 实时显示各选项当前票数
- 支持修改已投的票（重新选择覆盖旧记录）
- 匿名模式下其他用户看不到谁投了什么

---

### 2.4 查看结果

| 属性 | 说明 |
|------|------|
| **功能名称** | 投票结果展示 |
| **入口路径** | 活动详情页 → 结果标签页（package-vote/result） |
| **操作流程** | 1. 进入结果页面 → 2. 查看各选项得票数及占比 → 3. 查看投票明细（非匿名模式）→ 4. （房主）执行最终确认/锁定 |
| **涉及云函数** | `getRoom`, `countVotes`, `getLockedResult` |
| **前置条件** | 有至少一票被提交，或房间已被锁定 |
| **数据库集合** | votes, rooms, room_participants |

**结果状态：**
- **进行中**：实时更新票数，可继续投票
- **已锁定**：票数冻结，显示最终结果
- **已结束**：超过截止时间自动归档

---

### 2.5 房间管理

| 属性 | 说明 |
|------|------|
| **功能名称** | 房主控制台 |
| **入口路径** | 我创建的活动 → 控制台（package-vote/control） |
| **操作流程** | 1. 进入控制台 → 2. 查看参与者列表 → 3. 执行操作（锁定/修改/删除/提醒） |
| **涉及云函数** | `lockRoom`, `updateRoom`, `deleteRoomById`, `sendReminder`, `getRoomDetail` |
| **前置条件** | 当前用户为房间创建者 |
| **可用操作** | 手动锁定房间、修改房间信息、删除房间、发送提醒通知 |

---

### 2.6 退出与删除

| 属性 | 说明 |
|------|------|
| **功能名称** | 退出活动 / 删除活动 |
| **退出入口** | 活动详情页 → 退出按钮（普通参与者） |
| **删除入口** | 控制台 → 删除按钮（仅房主） |
| **涉及云函数** | `quitRoom`, `quitGroupOrder`, `deleteRoomById` |
| **前置条件** | 退出：已加入；删除：是房主 |
| **级联影响** | 删除房间时同步清理 participants、votes 等关联数据 |

## 模块三：拼单系统

### 3.1 拼单详情与参与

| 属性 | 说明 |
|------|------|
| **功能名称** | 拼单活动完整流程 |
| **入口路径** | package-vote/group-detail |
| **操作流程** | 1. 打开拼单活动 → 2. 浏览商品选项（图片+名称+价格）→ 3. 勾选想要的商品及数量 → 4. 确认提交 → 5. 查看汇总订单 |
| **涉及云函数** | `joinGroupOrder`, `getGroupOrder`, `getGroupOrderParticipants`, `quitGroupOrder` |
| **前置条件** | 活动未截止、未达到人数上限 |
| **数据库集合** | rooms, group_order_participants |

**核心差异点：**
- 普通投票：每人投N个选项中的M个
- 拼单：每人选择多个商品，每个商品有数量属性
- 结算环节：自动汇总所有人的选择，生成订单清单

---

### 3.2 拼单结算

| 属性 | 说明 |
|------|------|
| **功能名称** | 订单汇总与结算 |
| **入口路径** | 拼单详情 → 结算按钮（package-vote/settlement） |
| **操作流程** | 1. 点击结算 → 2. 系统统计所有参与者的选择 → 3. 生成分类汇总表 → 4. 显示总金额和人均 → 5. 导出/分享结算单 |
| **涉及云函数** | `getGroupOrder`, `getGroupOrderParticipants` |
| **前置条件** | 拼单活动已截止或手动关闭 |
